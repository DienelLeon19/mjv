# SOFÍA 2.0

- Respeta la estructura React + Vite + TypeScript en frontend y Node.js + Express + TypeScript en backend. Usa pnpm y consulta los manifiestos antes de ejecutar comandos.
- Para un cambio en React, aplica frontend-developer. Para contenedores, usa docker-expert. En una revisión de API, combina api-security-best-practices con postgresql si el cambio alcanza el esquema o las consultas.
- Ante fallos, usa systematic-debugging para aislar la causa y test-driven-development para reproducir la regresión cuando corresponda. Limita brainstorming a la fase de diseño y code-reviewer a revisiones.
- Mantén separadas las fuentes oficiales SUNAT, los documentos internos y las respuestas generadas. Conserva procedencia y fecha de consulta, aplica permisos de acceso antes de recuperar documentos y evita incluir datos sensibles en prompts o logs.
- Verifica los contratos y las convenciones del repositorio antes de proponer cambios de infraestructura, dependencias o arquitectura.
